# 🇬🇧 README (English)

## Worktime Processing & Viewing Tools

This project contains two browser-based tools:

### 1. Worktime Processor
Converts an Excel file into a JSON file while applying all business rules:

- Sessions under 60 minutes become **60 minutes minimum**
- Sessions over 60 minutes are **rounded to the nearest 10 minutes**
- Consecutive sessions (the next starts exactly when the previous ends) are **merged before rounding**
- Monthly totals are rounded **up** in **30-minute blocks**

The tool reads the Excel file, processes all workers and sessions, and automatically downloads the resulting JSON.

### 2. Worktime JSON Viewer
Loads and displays the JSON generated by the processor.

You can view:

- Workers and their total monthly rounded hours  
- Individual sessions  
- Merged consecutive blocks  
- Original and adjusted durations  
- Dates, locations, part numbers  
- Expandable detailed tables  

Everything works fully in the browser with no installation.

### Usage Summary
1. Open the Processor → Upload Excel → Download JSON  
2. Open the Viewer → Load JSON → Explore results

# 🇪🇸 README (Español)

## Herramientas para Procesar y Visualizar Horas Laborales

Este proyecto incluye dos herramientas que funcionan directamente en el navegador:

### 1. Procesador de Horas Laborales
Convierte un archivo Excel en un archivo JSON aplicando todas las reglas:

- Sesiones de menos de 60 minutos → **mínimo 60 minutos**
- Sesiones mayores de 60 minutos → **redondeo a los 10 minutos más cercanos**
- Sesiones consecutivas (la siguiente empieza al terminar la anterior) → **se fusionan antes del redondeo**
- Total mensual → **redondeo hacia arriba** en bloques de **30 minutos**

El procesador analiza el Excel y descarga automáticamente el JSON resultante.

### 2. Visor de JSON de Horas Laborales
Carga y muestra el JSON generado por el procesador.

Permite ver:

- Trabajadores y sus horas totales mensuales  
- Sesiones individuales  
- Bloques consecutivos fusionados  
- Duraciones originales y ajustadas  
- Fechas, ubicaciones, números de parte  
- Tablas detalladas expandibles  

Funciona por completo en el navegador sin instalar nada.

### Resumen de uso
1. Abrir el Procesador → Cargar Excel → Descargar JSON  
2. Abrir el Visor → Cargar JSON → Ver resultados
